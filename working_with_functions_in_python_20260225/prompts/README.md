# Python tanulás AI segítségével

Ebben a mappában olyan prompt sablonokat találsz, amelyekkel hatékonyabban tanulhatsz Pythont nagy nyelvi model ágensek (pl. ChatGPT, Claude) segítségével.

## Hogyan használd?

1. Válassz egy promptot az alábbi listából
2. Másold be a promptot a választott AI chat dobozába
3. Cseréld ki a példakódot a saját kódodra, amit meg szeretnél érteni
4. Az AI részletesen elmagyarázza a kód működését

| [Beépített függvény magyarázat](./prompt-explain-and-provide-relevant-use-cases.md) | Részletesen bemutat egy Python beépített függvényt: szintaxis, paraméterek, használati esetek és példák |
